# 台灣生存戰 V19.3（完整遊戲）

## 啟動方式

1. 解壓縮整個 ZIP。
2. 打開 `taiwan-survival-main` 資料夾。
3. 用手機或電腦瀏覽器開啟 `index.html`（介面樣式依賴 Tailwind CDN，需能連線至該 CDN）。

請保留資料夾內的 JS 檔案與 `taipei_map_clean_v12.jpg`。不需要下載或恢復舊版廢棄地圖 PNG。

## V19.3 本次調整：NPC 搜刮攻擊玩家

- NPC **只有完成一次搜刮**，才有機率遭遇同區真人玩家。是否攻擊依簡單／困難模式、雙方戰力與血量判斷，不是必定攻擊。
- 當 NPC 主動攻擊真人玩家時，直接依共用傷害與角色技能規則結算，在探索頁戰報顯示誰打你和實際傷害；**不強制跳出戰鬥視窗**。
- 不會附贈玩家自動反擊；玩家若要主動出手，仍需要自己搜刮觸發遭遇，再選擇普通攻擊、技能或無視。
- 攻擊有全場及單隻 NPC 的短暫間隔，防止同一秒多名 NPC 連續偷襲。
- 玩家搜刮時若受到攻擊，通常仍可完成當次搜刮；若玩家死亡或被角色技能強制移動到別區，則取消原本搜刮。
- 玩家閃避、反傷、殘血被動、免死等規則繼續使用同一套傷害結算。
- NPC 遇到 NPC 的交戰仍需由搜刮觸發；不恢復原本無條件主動突襲與雙方自動反擊系統。

## 保留的 V19.2 功能

- 22 區有限物資池與重新平衡後的固定產地；不無限刷新物資、不顯示區域剩餘物資數量。
- NPC 每次搜刮隨機取得一件候選物資，而非預先從多件中挑選。
- 完整合成樹追蹤、已完成支線自動收合、底層素材產地、禁區灰字與地圖追蹤星星。
- 兩種 NPC AI 難度、六個背包格與角色技能／被動、角色選擇靠下排版、首頁與圖鑑分類、手機快速跟手拖曳。
- 兩個既有測試模式。

## 主要檔案

- `index.html`：首頁與遊戲 UI
- `lobby.js`：角色選擇、難度與測試模式
- `main.js`：遊戲時間、搜刮、合成、地圖與追蹤 UI
- `ai.js`：NPC 搜刮與發育、選敵、攻擊
- `combat.js`：遭遇與傷害結算
- `maps.js`：22 區初始物資分布
- `items_*.js`、`recipes.js`、`characters.js`、`game_config.js`：物品、配方、角色與設定
- `taipei_map_clean_v12.jpg`：目前使用的地圖圖片
