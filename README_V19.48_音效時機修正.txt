【台北倖存者 V19.48｜搜刮與受傷音效修正】

接在 V19.47 後安裝。只覆蓋下列程式檔案即可：
- index.html
- main.js
- ai.js
- audio_manager.js

更新：
1. 搜刮音效：成功開始「搜刮讀條」時播放，不再於找到物品時播放；搜刮完成、中斷或離開區域時停止。
2. NPC 命中玩家造成生命損失時播放「自己受傷」音效，閃避／無傷害不播放。
3. iPhone Safari：首次點擊後預先解碼短音效，優先透過 Web Audio 播放；失敗則保留 HTML 音訊備援。
4. 背景音樂與音效使用不同播放物件，SFX 不會中斷 BGM。
5. 已更新 HTML 腳本版本參數，讓手機在 GitHub Pages 更新後較不容易讀到舊 JS。

這次不需要重新上傳 MP3、圖片、角色素材，也不會修改角色數值或 AI 平衡。
首頁維持 V19.47 的背景與「台北／倖存者」排版。

驗證：Node.js 語法檢查；Chromium 中模擬搜刮開始／結束、NPC 造成玩家受傷、未遇敵無傷害、靜音與 Web Audio 疊加播放路徑均通過。
