台北倖存者 V19.54 — 拾獲「叮」聲修正（增量補丁）

修改內容：
1. 每次成功搜出任一物品（材料、武器、防具、補品），結果視窗每件彈出時各叮一次。
   重複道具也會響；同一視窗重繪不會重複響；沒找到任何道具不響。
2. 背景音樂與遊戲音效改為獨立音量與靜音，調整音樂不會把拾獲音效關掉。
3. 拾獲叮聲直接打包到 audio_manager.js，解決未上傳 MP3 或檔案快取造成的缺聲問題。
4. 音效在首次用戶操作後預先解碼成 Web Audio Buffer，可在搜刮倒數結束時播放。
5. 大廳音樂選單／對戰暫停選單中提供「試播拾獲叮聲」和音效音量設定。

本補丁沿用 V19.53 已有的拾獲提示音，並未把尚未經你選定的 A/B 新試聽版放進正式遊戲。

安裝：將壓縮檔內 TEST-GAME-main 的 3 個檔案覆蓋到遊戲根目錄：
- index.html
- main.js
- audio_manager.js

其他功能（屍體、技能、紅裝配方、地圖素材、背景音樂、三種寫實音效）均不變。
