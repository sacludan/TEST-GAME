# V19.43 黑暗生存配樂（A 風格）增量補丁

基於 V19.42。解壓後將 TEST-GAME-main 內的檔案覆蓋現有專案。

- 新增約 77 秒的原創循環 BGM（MP3），於正常/測試模式開始遊戲時播放。
- 大廳／遊戲探索面板都有「🎵」按鈕，可調整音量、靜音與試聽。
- 音量預設 30%，設定儲存於本機瀏覽器。
- 僅在使用者互動後開始播放，符合 iPhone Safari 自動播放限制。
- 網頁切到背景時暫停音樂。
- 不動角色技能、AI 邏輯、平衡模擬器，也不引入音樂模組至 balance.html。
- 本版只加入背景配樂，事件／戰鬥音效尚未實裝。

如需在本機試玩，建議以 `py -m http.server 8000` 從遊戲目錄啟動。
